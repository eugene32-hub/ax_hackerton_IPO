# 공모주 노트 (시연용 가상 화면)

DART 공시(증권신고서·투자설명서·증권발행실적보고서)를 바탕으로 공모주 청약 일정, 종목 상세, 공시 기반 챗봇 '유진이'를 보여 주는 해커톤 시연 화면이에요.

> 시연용 가상 화면이에요. 특정 종목의 매수·매도를 권하거나 수익을 보장하지 않아요.

## 파일
- `index.html` : 첫 화면(청약·상장 일정, 종목 검색)
- `detail.html` : 종목 상세(개요·기업·밸류에이션·배정 계산·비교·위험) + 유진이
- `api/yujin/[model].js` : Vercel 서버 함수. 유진이 질문을 서버의 `GEMINI_API_KEY`로 Gemini에 대신 물어요.
- `vercel.json` : 서버 함수 실행 시간을 최대 60초로 늘려요.

## API 키
API 키는 이 저장소에 들어 있지 않아요.
- Vercel에 배포하면 Vercel 환경변수 `GEMINI_API_KEY`에 넣은 키로 방문자 모두가 키 없이 유진이 AI를 써요.
- 서버 없이 파일로 열거나 GitHub Pages로 열면, 유진이 대화창 ⚙에서 각자 키를 넣어야 해요(그 브라우저에만 저장돼요). 키가 없으면 공시 데이터로 답하는 기본 모드로 동작해요.

## 남용 방지 (api/yujin/[model].js)
허용 모델 3개(gemini-3.8-flash, gemini-flash-latest, gemini-flash-lite-latest), 요청 본문 300KB, 답변 1500토큰, IP당 10분 30번·하루 1000번(서버 인스턴스마다 따로 세요. `DAILY_LIMIT` 환경변수로 조정).
